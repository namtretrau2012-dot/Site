🦈 Big Shark Menu v2 đang chạy!

Script đã được nạp. Nút 🦈 màu trắng sẽ xuất hiện ở góc trên bên phải màn hình.

  1. Bấm nút 🦈 để mở/đóng menu Big Shark.
  2. Bấm ⚡ KÍCH HOẠT BIG SHARK để bật/tắt hiệu ứng (bypass thật).
  3. Chọn Preset nhanh: Live · Podcast · Karaoke · Bass · Max.
  4. Chỉnh các thanh trượt: Gain Mic, Bass, Mid, Treble, Reverb, Độ dài vang.
  5. Vào Messenger web / Discord web / Google Meet → cấp quyền mic → hiệu ứng tự áp dụng.
⚠️ Quan trọng: Script chỉ hoạt động khi trang web bạn dùng có gọi getUserMedia(). Nếu không, nút sẽ hiện nhưng không có âm thanh nào bị ảnh hưởng.

Cách dùng: Mở Console (F12) của trang như messenger.com → paste toàn bộ code JS trong file này → Enter.
💡 Mẹo: Trạng thái ON/OFF và các thông số được tự động lưu vào localStorage. Lần sau mở lại sẽ nhớ cài đặt.
